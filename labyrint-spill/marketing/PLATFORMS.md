- **[now]** — works today (dev-feedback audience; the 16+ play-gate doesn't block it)

## Tier 1 — Roblox-native (free, highest ROI)

- **On-platform search + recommendations** — DONE (keyword description, Obby genre). Keep it fed: ship a small visible update every week or two; recency boosts ranking.
- **Roblox Group for the game** — create a group, post "shouts" (broadcasts) to members, link the game, pin it. Groups also give a community home. *[needs you to create the group — I can set it up with you.]*
- **Badges / update notes** — add a couple of free badges (e.g. "Reached level 10"); badge-hunters seek games with badges, and update notes refresh the page.
- **Roblox events / game jams / contests** — seasonal events and jams give free discovery spikes. *[mostly launch]*

## Tier 2 — Reddit (free; dev-feedback works now)

- **r/robloxgamedev** — DONE. Live post, monitored hourly, one helper engaged.
- **r/RobloxDevelopers** — dev feedback/showcase. **[now]** — next auto-post target.
- **r/playmygame** — good sub, but posts must be **freely playable** → blocked until 16+ lifts. **[launch]**
- **r/roblox** — huge but player-facing with strict self-promo rules; drive-by links get removed. **[launch]**
- **Niche/genre subs** (maze/puzzle/obby communities) — smaller, more engaged.
- Avoid r/gaming (no free promo).

## Tier 3 — Discord (free, needs your account + care)

- **Build your OWN game Discord** — highest retention lever (communities retain ~1.5–2.5× more 30-day players). Link it from the game. **[needs you]**
- **Roblox dev/advertising servers** (find via top.gg, Disboard, Discadia) — post only in the correct feedback/showcase channels, follow each server's rules; most "advertising" servers are low-quality/spam, so be selective. **[needs you]**

## Tier 4 — Short-form video (the biggest organic driver — needs footage)

- **TikTok**, **YouTube Shorts**, **YouTube** — Roblox discovery increasingly happens here. A 15–30s clip of a fast run + a near-miss + the win screen. Blocked until we have footage (a Reddit helper or verification). **[needs you + footage]**

## Tier 5 — Cross-promotion

- Partner with other small Roblox devs to shout each other's games (free, mutual). **[needs you]**

The Reddit account is fairly new, so **don't blast**. One new venue per day, each post
tailored to that community's rules (flair, feedback-framing, no drive-by ads). Keep the
hourly monitor on every posted thread and reply to helpers.
